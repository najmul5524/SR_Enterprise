# SR Enterprise (এস আর এন্টারপ্রাইজ)
### পৌল্ট্রি ও গরুর খাদ্য, ঔষধ ডিলারশিপ এবং খামারি হিসাব ব্যবস্থাপনা সফটওয়্যার

SR Enterprise এর জন্য তৈরি একটি পূর্ণাঙ্গ ডিজিটাল ডিলার ও খামার ব্যবস্থাপনা ওয়েব অ্যাপ্লিকেশান। এটি পৌল্ট্রি শেডে বাচ্চা তোলা থেকে শুরু করে পূর্ণ মুরগী বিক্রি পর্যন্ত যাবতীয় খরচ (বাচ্চা, খাদ্য, ঔষধ) ট্র্যাকিং, কিউআর কোড ভিত্তিক স্টক ইনভেন্টরি, খামারিদের খতিয়ান ও লাইভ খামারি পোর্টাল পরিচালনা করে।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Core Features)

1. **ডিলার কন্ট্রোল সেন্টার (Owner / Dealer Dashboard):**
   - মোট খামারি বকেয়া পাওনা (Total Outstanding Dues)
   - চলতি শেডে মোট বিনিয়োগ (বাচ্চা + খাদ্য + ঔষধ)
   - আজকের মালামাল ডেলিভারি ও নগদ/বিকাশ আদায়
   - কম স্টক সতর্কবার্তা (Low Stock Alerts)

2. **কিউআর কোড (QR Code) ইনভেন্টরি ম্যানেজমেন্ট:**
   - খাদ্য বস্তা ও ঔষধের বোতলে স্ক্যানযোগ্য কিউআর কোড
   - মোবাইল ক্যামেরা দিয়ে সরাসরি রিয়েল-টাইম বারকোড/কিউআর স্ক্যান
   - স্বয়ংক্রিয় স্টক হ্রাস/বৃদ্ধি এবং মিনিমাম স্টক অ্যালার্ট
   - প্রিন্টযোগ্য কিউআর স্টিকার লেবেল জেনারেটর (A4 ও রোল প্রিন্টার সাপোর্ট)

3. **চুক্তিভিত্তিক শেড ও ব্যাচ মডেল (Contract Farming Shed Lifecycle):**
   - বাচ্চা ক্রয় খরচ (Day Old Chicks)
   - প্রতিদিনের খাদ্য ও ঔষধ ডেলিভারি লগ
   - মর্টালিটি ট্র্যাকিং (মুরগী মারা যাওয়ার হিসাব)
   - **শেড সমাপনী ও বিক্রয় হিসাব (Shed Harvest Settlement):**
     - মুরগীর মোট বিক্রিত সংখ্যা, ওজন (কেজি) ও দর
     - মোট বিক্রয়লব্ধ টাকা থেকে ডিলারের বিনিয়োগ সমন্বয়
     - খামারির নীট মুনাফা স্বয়ংক্রিয় হিসাব ও খাতা আপডেট

4. **চালান তৈরি ও ক্যাশ মেমো (POS & Memo Print):**
   - খামারি ও রানিং শেড সিলেক্ট করে চালান তৈরি
   - বাকি (Credit), নগদ ও আংশিক পেমেন্ট
   - বাংলায় প্রিন্ট উপযোগী ক্যাশ মেমো ভাউচার

5. **খামারি লাইভ পোর্টাল (Farmer Mobile Portal):**
   - মোবাইল নম্বর ও পিন দিয়ে খামারিদের নিজস্ব লগইন
   - রানিং শেডের লাইভ বয়স, খাদ্য গ্রহণ ও খরচের হিসাব
   - নিজস্ব হিসাবের খতিয়ান (Ledger Statement)
   - মোবাইল থেকে ফিড ও ঔষধের রিকুয়েস্ট পাঠানোর সুবিধা
   - খামারির ডিজিটাল কিউআর কার্ড

6. **ক্লাউড স্টোরেজ ও ডাটাবেস আর্কিটেকচার:**
   - **Cloudinary:** পণ্য, খামারি ও ভাউচার স্লিপের ছবি ক্লাউডিনারিতে সংরক্ষিত হয় (যাতে Render এর ফ্রি 5GB ব্যান্ডউইথ সাশ্রয় হয়)।
   - **Firebase Firestore:** গুগল ফায়ারবেস কনসোলের মাধ্যমে রিয়েল-টাইম ক্লাউড ডেটাবেস সিঙ্ক (ক্রেডেনশিয়াল না থাকলে স্বয়ংক্রিয়ভাবে লোকাল SQLite মোডে কাজ করে)।
   - **ডিজাইন ও ফন্ট:** `https://qr-printing.onrender.com/` এর অনুরূপ `Hind Siliguri` ফন্ট এবং মডার্ন Tailwind CSS রেসপন্সিভ ডিজাইন।

## 🚀 লোকাল রান করার নিয়ম (Local Setup)

```bash
# ১. ডিপেনডেন্সি ইন্সটল করুন
pip install -r requirements.txt

# ২. সার্ভার চালু করুন
uvicorn main:app --reload --port 8000
```
ব্রাউজারে ওপেন করুন: `http://localhost:8000`

## ☁️ Render এ ডেপ্লয় করার গাইড (Render Deployment)

1. এই প্রজেক্টটি গিটহাবে পুশ করুন।
2. [Render Dashboard](https://dashboard.render.com/) এ গিয়ে **New Web Service** তৈরি করুন।
3. নিচের সেটিংস ব্যবহার করুন:
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
4. **Environment Variables:**
   - `APP_ENV`: `production`
   - `SECRET_KEY`: `your_random_secret_key`
   - `CLOUDINARY_CLOUD_NAME`: `আপনার ক্লাউডিনারি ক্লাউড নেম`
   - `CLOUDINARY_API_KEY`: `আপনার ক্লাউডিনারি এপিআই কি`
   - `CLOUDINARY_API_SECRET`: `আপনার ক্লাউডিনারি সিক্রেট`
   - `FIREBASE_CREDENTIALS_JSON`: *(Firebase Service Account JSON ফাইলের সম্পূর্ণ কন্টেন্ট)*
